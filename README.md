# Buscador de países

Práctica de la Sesión DOM 4 (DWC - 2º DAW): buscador contra countries.dev, lista de favoritos y ordenación por población.

## Cómo abrirlo

Usa módulos ES, así que no funciona abriendo `index.html` con doble clic. Hay que servirlo por HTTP:

- VS Code: Live Server → Open with Live Server
- Python: `python -m http.server 8000` y abrir http://localhost:8000
